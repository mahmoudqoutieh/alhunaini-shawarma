# شاورما الهنيني

موقع صفحة واحدة متحركة لمطعم شاورما الهنيني: ثلاثة مشاهد يتنقل بينها الزائر بالتمرير (السيخ، اللفّة على النار، البرجر على الصاج)، مع قائمة طعام منبثقة.
الموقع ثابت (ملفات HTML وCSS وJS فقط) ولا يحتاج إلى خادم Node على الاستضافة، ولا يعتمد على أي خدمة خارجية سوى خط Cairo من Google Fonts.

## تجربتان للعرض

- **الحاسوب:** مشهد متحرك واحد تتحكم به حركة التمرير (فيديو يتقدم ويتراجع مع التمرير) وتأثيرات الماوس.
- **الهاتف** (شاشة حتى 900 بكسل، أو جهاز لمس حتى 1280): تصميم منفصل أخف بكثير: أقسام بحجم الشاشة تنزلق بالتمرير، وفيديو قصير يعمل تلقائياً في القسم الظاهر فقط، وقائمة طعام مدمجة بصور مصغّرة. لا يُحمَّل كود الحاسوب على الهاتف.
  ملفات فيديو الهاتف في `public/assets/mobile` (والصورة الأولى لكل فيديو بجانبه).

## التشغيل محلياً

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # ينتج مجلد dist
npm run preview    # معاينة نسخة البناء
```

يتطلب Node 20 أو أحدث.

## تعديل بيانات المطعم

- رقم الهاتف والواتساب والعنوان: `src/site-info.ts`. اترك القيمة فارغة لإخفاء الزر.
  الواتساب بصيغة دولية بدون `+` أو أصفار، مثل `966500000000`.
- أصناف القائمة وأوصافها: `src/components/site/menu-panel.tsx` (المصفوفة `products`).
- نصوص المشاهد الثلاثة: `src/scroll-scrub-scenes.tsx`.
- الألوان: أعلى `src/styles.css` (المتغيرات `--h-*`).

## الرفع على هوستنجر

### الطريقة 1: رفع يدوي (الأسهل)

1. نفّذ `npm run build`. (اضبط عنوان موقعك أولاً لتظهر صورة المشاركة بشكل صحيح: `SITE_URL=https://example.com npm run build`، وغيّر العنوان إلى نطاقك.)
2. من لوحة هوستنجر افتح **مدير الملفات** ثم المجلد `public_html`.
3. احذف الملفات الافتراضية، وارفع **محتويات** مجلد `dist` (وليس المجلد نفسه).
   تأكد أن الملف المخفي `.htaccess` ارتفع أيضاً (فعّل خيار إظهار الملفات المخفية).
4. افتح نطاقك للتأكد.

### الطريقة 2: رفع تلقائي من GitHub

الملف `.github/workflows/deploy.yml` يبني الموقع ويرفعه إلى هوستنجر عند كل `push` على الفرع `main`.

1. ارفع المشروع إلى مستودع GitHub.
2. في هوستنجر: **الملفات ← حسابات FTP**، وأنشئ حساباً (أو استخدم الحالي) وسجّل الخادم واسم المستخدم وكلمة المرور.
3. في GitHub: **Settings ← Secrets and variables ← Actions**:
   - Secrets: `FTP_SERVER` و`FTP_USERNAME` و`FTP_PASSWORD`.
   - Variables: `SITE_URL` (مثل `https://example.com`) و`FTP_DIR` (اختياري، الافتراضي `/public_html/`).
   - `FTP_DIR`: مجلد الموقع على هوستنجر. إن كان حساب FTP الذي أنشأته مقيّداً داخل `public_html` أصلاً فاجعله `/`.
   - `FTP_PROTOCOL` (اختياري): `ftp` (الافتراضي) أو `ftps` إذا كان خادمك يدعم التشفير.
4. أي `push` جديد على `main` ينشر الموقع تلقائياً. يمكنك أيضاً تشغيله يدوياً من تبويب **Actions**.
   إن لم تُضف الأسرار بعد، يبني التشغيل الموقع فقط ويظهر تحذير يوضح ما ينقص، وتجد نسخة البناء جاهزة للتنزيل باسم `site-dist` في صفحة التشغيل.

## ملاحظات

- ملفات الفيديو الأكبر حجماً حوالي 6MB، أقل بكثير من حد GitHub (100MB لكل ملف)، فلا حاجة إلى Git LFS.
- يُحمَّل على الجوال فيديو طولي خفيف (حوالي 1MB لكل مشهد)، وعلى الحاسوب نسخة أعلى جودة.
- إن أردت استبدال فيديو، احتفظ بالأسماء نفسها وأعد ترميز الصورة الأولى (`*-poster.jpg`) من أول إطار في الفيديو المرمّز.
